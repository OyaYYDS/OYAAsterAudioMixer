# 知识库：ASTER 多座位机制与音频

> 置信度标注：✅ 高 ｜ 🟡 中 ｜ ⚠️ 未验证

## 会话/账户模型

- ASTER（IBik）：一台 PC 通过软件分割成多座位（最多 12 终端），每座位独立显示器/键鼠/声卡，互不干扰。✅（官方文档 + 中文渠道一致）
- 每座位 = 独立 Windows 会话 + 独立用户账户（各输各的 PIN/密码登录）✅ —— 这是"按用户账户名判定"可行性的基础。

## ASTER 自带音频能力（"会话级"粒度）

- ASTER Control 中按 Place 1/2（座位）拖拽分配声卡等设备；可将某声卡只分给某座位。✅
- 分配后需在各座位自己的 Windows 声音设置里设默认设备 → 每个座位拥有独立默认音频设备。✅
- 官方/中文资料称声音"非常容易分开，无需添加 USB 声卡"（HDMI/USB 声卡可分配得更清晰）。✅

## 对本项目的含义

- ASTER 已覆盖"会话级"粒度（整个座位的默认设备）；本项目做的是更细的"应用级"粒度 + 自动化（新进程自动跟随用户路由，免手动进设置页）。
- **失败预案路线**：若 P0 判据（每应用持久化按用户隔离）不成立 → 降级为每座位"会话级默认设备"：`IPolicyConfig::SetDefaultEndpoint`（同为未公开 COM，按会话隔离，ASTER 设置页自身即此机制）。🟡（方案合理，未实测）
