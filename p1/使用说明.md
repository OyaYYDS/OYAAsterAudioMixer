# OYA ASTER 音量合成器 — 使用说明

## 这是什么

每座位一个的音量合成器 + 自动路由：
- **自动**：本座位任何程序一出声，自动路由到该用户在 config.json 里配置的扬声器/麦克风
- **手动**：在合成器里拖音量、静音、改某程序的输出设备（改过设备的程序 agent 永不再碰，直到你改回"自动"）
- 两座位完全独立（各自的会话、各自的用户目录）

## 启动

- **双击 `OYAAsterAudioMixer.exe`** → 托盘图标 + 合成器窗口（GUI 开着=自动路由在跑）
- 窗口点 X 只是隐藏到托盘；退出走托盘右键"退出"
- 登录自启：**设置窗口 → 其他 → 勾选"本座位开机自启"**（每座位各勾一次；取消勾选即卸载）

## 合成器窗口

| 元素 | 说明 |
|---|---|
| 应用行 | 本座位正在出声的程序（1 秒刷新） |
| 音量滑条 | 拖完生效；只影响该程序 |
| 静音勾 | 只静音该程序 |
| 扬声器下拉 | `自动（跟随规则）`=agent 按 config 路由；`系统默认`=恢复系统默认设备；具体设备=手动路由（记录到你的用户目录） |
| 麦克风下拉 | 同上，控制该应用的录音设备；与扬声器**各自独立**手动/自动 |
| 右键行 | 加入黑名单（agent 停止路由该程序，支持通配在设置里改） |
| 顶部按钮 | 日志（打开日志文件夹）、设置 |

## 设置窗口

- **路由规则**：用户→扬声器/麦克风/排除名单 的表格；`*` 通配可作未匹配兜底；保存即热重载
- **手动覆盖**：列出你手动改过设备的程序，点"恢复自动"交还 agent 接管
- **其他**：本座位开机自启开关、打开日志

## 配置文件

- 路由规则：`p1\config.json`（exe 同目录优先，其次 %ProgramData%\AsterAudioRouter\config.json）
- 手动覆盖：`%AppData%\AsterAudioRouter\overrides.json`（**每个用户各一份**，两座位互不影响）
- 日志：`p1\p1logs\`

## 命令行（进阶）

```
OYAAsterAudioMixer.exe --agent       后台运行（无窗口，纯自动路由）
OYAAsterAudioMixer.exe --dry-run     试运行：只记录将执行的路由
OYAAsterAudioMixer.exe --status      查看配置/匹配规则/出声进程
OYAAsterAudioMixer.exe --install     写入本座位登录自启
OYAAsterAudioMixer.exe --uninstall   移除自启
```

## 注意

- 每个座位同一时间只能有一个实例（GUI 或 --agent 二选一）
- voicemeeter8 必须在排除名单（否则混音器输出回路到自身输入）
- 升级版本前：两个座位都先双击 `停止agent.cmd` 结束旧实例
